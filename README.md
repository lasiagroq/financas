# Delícias da JU

Vitrine de pedidos para a marmitaria Delícias da JU.

## Rodar localmente

```bash
python main.py
```

Depois, abra [http://localhost:8000](http://localhost:8000).

## Verificar localmente

O projeto não depende de um pacote baixado pelo npm para o smoke test. Execute:

```bash
python -m unittest tests/test_server.py
node --check script.js
```
